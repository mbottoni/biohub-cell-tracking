equations: `edge_J·k = 0.88` and `1.1·edge_J + 0.1·div_J = 1.00`. Under every assumption about the
unknown division term, **k = N_pred/est_n_nodes ≈ 0.97–1.02 and the multiplier ≈ 1.00** — the node
